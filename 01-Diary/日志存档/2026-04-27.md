项目背景：
FedDGC 是 FL + LoRA 论文项目。基础模型主要是 LLaMA-1B，数据主要是 SuperNI。核心问题是：在任务异构联邦学习中，FedAvg 对客户端 LoRA 有效更新 ΔW = scaling * B A 的 tail/floor 谱方向存在选择性稀释；这些 tail/floor 方向在 motivation 中被证明更偏客户端个性化、功能相关。FedDGC 的目标是保护这些客户端私有脆弱方向，提升 personalized FL 的本地适配效果，同时不显著牺牲 clean global behavior。

当前正式方法版本：
FedDGC-v9，已经收缩为：
- tail-restricted frozen bypass
- 只选择局部 ΔW 谱方向中 tail/floor 候选池，当前 q_tail=0.6
- correction cache: C_c = Σ_i δ_i u_i v_i^T，其中 δ_i 是 dilution gap
- C_c 不写入 LoRA 参数，不上传，不进入服务器聚合
- 在客户端 forward 中作为 frozen bypass residual 加入：
  output = base + LoRA + λ_eff C_c x
- 当前更推荐 eta-calibrated strength：
  λ_{c,l} = η * ||s_l B_l A_l||_F / (||C_{c,l}||_F + eps)
- 主实验强候选 eta 是 3.5 和 4.0；早期 eta=0.5 太保守。
- gate 当前设置里可以有，但 gate_batch_size=0 时等价于无 gate；已有观察是 gate-on/off 经常一致。

2. 关键技术概念

FFA-LoRA：冻结一个 LoRA 因子 A，只训练另一个因子 B。仅聚合 B，因此 B 会受到 dilution 影响。

FedSA-LoRA：同时训练 A 和 B，但只上传 A。B 保持本地私有。只有 A 会受到 dilution 影响。
