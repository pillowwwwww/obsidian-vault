> ### 一、项目概述
>
> **论文标题：** FedReCall: Recalling Client-Specific Directions in Federated LoRA Fine-tuning
>
> **投稿目标：** NeurIPS 2026
>
> **核心思想：** 联邦 LoRA 微调中，factor-wise 聚合（分别平均 A 和 B）会系统性地稀释客户端特异性奇异方向（directional dilution）。FedReCall 是一个客户端私有的 plug-in：每轮聚合后，客户端测量自己的 dilution gap，将被稀释的方向存入私有 frozen cache，下次参与时作为 frozen low-rank bypass 注入本地训练，由 one-batch quality gate 守护。Cache 不上传，不改变服务端聚合、通信量或可训练参数。
>
> **算法全称：** FedReCall = Federated Re-injection of Client-Adaptive Lost directions

## 我对方法的核心理解

FedReCall 针对的并不是一般意义上的“低秩容量不足”，而是 factor-wise averaging 的双线性错配：

\[
\left(\sum_c p_c B_c\right)\left(\sum_c p_c A_c\right)
\neq
\sum_c p_c B_cA_c.
\]

这会让客户端本地有效更新中的方向在聚合后受到不同程度的破坏。FedReCall 对每个本地奇异方向测量：

\[
\alpha_i=\langle \Delta W_{\rm glob},u_iv_i^\top\rangle_F,\qquad
\delta_i=\max(0,\sigma_i-\max(\alpha_i,0)).
\]

然后仅保留 tail/floor 区域中非退化且确实存在正 dilution gap 的方向，构造客户端私有 frozen cache。下一次参与时，用 η 做逐层范数校准，并通过 one-batch gate 决定是否注入低秩 bypass。

一个很重要的递归细节是：如果上一轮 bypass 被 gate 接受，本轮 cache 应当从“本轮训练后的 LoRA 更新 + 激活的旧 bypass”组成的 effective update 中重新估计，而不是只分解干净的 \(BA\)。核心 FedIT 路径确实实现了这一点：[main.py](<./Subspace_LoRA/main.py:825>)。

FedReCall 对全局模型的改善是间接产生的：cache 不上传，但 frozen bypass 会改变本地训练期间 \(A,B\) 的优化轨迹，随后上传的 clean factors 因而可能更好。这个机制解释了为什么“私有记忆”有可能改善 global model，而不需要把 cache 聚合到服务器。

## 当前证据的真实强弱

方法层面的几何动机是连贯的，核心 FedIT 实现也基本忠实于论文。最强的实证信号是 FFA-LoRA：在相对公平的 best-round 口径下，1.3452→1.0898 的约 19% personalized-loss 改善仍然成立。

但论文现在最危险的不是方法概念，而是实验取数与可复现性：

- 主表多数行不是“一个 run 的同一轮”。FLoRA、FFA、FedSA 存在跨 η 或跨轮次取列，FedDPA-T 2× 的论文 worst loss 2.001 与对应轮实际约 1.512 不符。
- FLoRA 在统一条件下的公平收益约为 **1.1%**，不是论文展示的 9.9%；FedSA 公平收益约为 **3.1%**，且个性化 ROUGE 存在下降。
- 论文声称“除非另有说明均为三种子平均”，但主表大量数据是单种子、best-round 或混合来源：[论文 L477](<./FedDGC_writing_Formatting_For_NeurIPS_2026/neurips_2026.tex:477>)。

   \sum_c p_c\Delta W_c.
   \]

2. **factor-wise LoRA 的额外双线性误差**

   定义

   \[
   \bar B=\sum_c p_cB_c,\qquad \bar A=\sum_c p_cA_c.
   \]

   则

   \[
   \sum_c p_cB_cA_c-\bar B\bar A
   =
   \sum_c p_c(B_c-\bar B)(A_c-\bar A).
   \]

   右边是因分别平均 LoRA factors 而额外产生的“因子协方差项”。它不存在于直接平均完整 \(\Delta W_c\) 的方法中。

因此准确表述应当是：

> FedReCall 不声称客户端方向冲突是 LoRA 独有的；论文研究的是 factor-wise LoRA aggregation 在一般联邦冲突之外引入的额外双线性 directional distortion。

这是 rebuttal 中最有价值的理论补充之一，同时回答 yFcC 的理论问题。

## AC 提出的四个核心任务

### 1. “更全面的敏感性分析”

这不仅是 η sweep。它实际上汇总了三位 reviewer 的多个问题：

- η sensitivity；
- 所有聚合器使用统一 η；

- 数值过滤阈值；

其中优先级最高的应该是：

1. fixed-η across aggregators；

4. rank/participation 下的机制指标。

需要避免只展示每个聚合器各自最优的 η。AC 想知道的是：如果不进行精细调参，FedReCall 是否依然稳定有效。

### 2. “弱方向是信号还是噪声，以及是否是 LoRA 特有失真”

这里包含两个不同问题。

#### 问题 A：弱方向为什么不是噪声？

我们不能声称“所有弱奇异方向必然有用”。更严谨的表述应是：

- tail/floor 只是候选方向先验；
- \(\delta_i>0\) 要求该方向确实在聚合后发生可观测缺失；
- \(\sigma_i\ge\tau_l\) 排除数值退化方向；
- one-batch gate 最终进行功能验证，只在方向降低客户端损失时启用。

可以给出一个基于局部损失光滑性的充分条件。若客户端损失 \(L_c\) 是 \(L\)-smooth，对单位方向 \(\phi\) 注入幅度 \(\epsilon\)，则：

\[
L_c(W+\epsilon\phi)
\le
L_c(W)
+\epsilon\langle\nabla L_c(W),\phi\rangle
+\frac{L\epsilon^2}{2}.
\]

因此，只要

\[
\langle\nabla L_c(W),\phi\rangle<-\frac{L\epsilon}{2},
\]

该方向即使奇异值较小，也会降低客户端损失。FedReCall 的 gate 正是在经验上检验这个条件，而不是假设所有 tail directions 都有用。

#### 问题 B：这是一般 FL 冲突，还是 factor-wise LoRA 特有问题？

这里需要明确承认：客户端方向冲突不是 LoRA 独有的。

但 factor-wise LoRA aggregation 会在一般更新抵消之外增加一个额外的双线性误差。令

\[
\bar B=\sum_c p_cB_c,\qquad
\bar A=\sum_c p_cA_c.
\]

直接平均有效更新为

\[
\Delta W_{\mathrm{exact}}=\sum_c p_cB_cA_c,
\]

而 factor-wise aggregation 得到

\[
\Delta W_{\mathrm{factor}}=\bar B\bar A.
\]

两者之差为：

\[
\Delta W_{\mathrm{exact}}-\Delta W_{\mathrm{factor}}
=
\sum_c p_c(B_c-\bar B)(A_c-\bar A).
\]

右侧是客户端 LoRA factors 的协方差项。它是分别聚合 \(A\) 和 \(B\) 所引入的额外失真，在直接平均完整有效更新时不存在。

因此 rebuttal 应将论文表述修正为：

> FedReCall 不声称客户端方向冲突是 LoRA 独有现象；它针对的是 factor-wise LoRA aggregation 在一般联邦异质性之外引入的额外双线性方向失真。

这是同时回答 AC、yFcC 和 TQRP 的核心理论论证。

### 3. “收敛、gate 和 cache stability”

AC 对这一部分的要求非常具体，至少需要提供：

- 不经过 EMA 的 raw personalized/global loss；
- 每轮 gate acceptance rate；
- round 50+ 的结果；
- 最后一段训练窗口的平均值或趋势，而不能只报告某个最优轮；
- cache age 与 gate acceptance/loss improvement 的关系；
- gate-off 或 stale-cache 对照。

关于 cache staleness，首先应澄清当前算法：

- cache 不会跨轮无限叠加；
- 客户端再次参与后会根据新的本地训练结果和聚合后模型重新构造 cache；
- 新 cache 覆盖旧 cache；
- 使用旧 cache 前必须通过 one-batch gate。

周期刷新、EMA 和 decay 可以作为补充消融，但不应让审稿人误以为当前方法完全没有刷新机制。

最有价值的定量分析可能是：

| Cache age | Gate acceptance | Bypassed loss improvement |
|---|---:|---:|
| 1–2 rounds | … | … |
| 3–5 rounds | … | … |
| >5 rounds | … | … |

如果 cache 越旧越容易被 gate 拒绝，就能直接证明 gate 确实在控制 staleness。

### 4. “rank=16、30% participation 和适用边界”

AC 不接受只说“总体趋势仍然正面”，而是希望明确解释负例。

合理的机制解释是：

- **rank=16**：LoRA 可表达的弱方向更少，tail/floor 候选集合更小，FedReCall 能恢复的额外客户端信号有限。
- **30% participation**：更多客户端参与后，基础聚合器可能更稳定，剩余 dilution 变小；原本适用于稀疏参与的 η 可能出现轻微过补偿，因此 personalized loss 不再占优。

但仅有解释还不够。最好同时报告：

- 平均相对 dilution gap；
- 每层 eligible direction 数量；
- cache norm ratio；
- gate acceptance rate；
- 不同 participation 下的最佳或固定 η。

这样可以证明负例与“剩余 dilution 变弱”一致，而不是算法随机失效。

AC 还明确要求：

- 更大客户端规模，例如 100/200 clients；
- 不同异质性水平。

异质性实验最好直接控制 task-type diversity，例如在尽量匹配客户端数和样本量的情况下构造：

- 低异质性：少量 task types；

- 高异质性：当前 23 task types。

如果 FedReCall 的收益随异质性或 measured dilution 增强，就能显著强化论文机制。

## 启动前必须解决的三个阻塞问题

### 1. 当前 plugin 版本并不统一

这不是历史实验数据来源问题，而是新 rebuttal run 实际会运行什么算法的问题。

- FLoRA 当前使用 `include_active_cache=False`，即 clean-pack variant，不是论文中的递归 effective-update 版本：[feddgc_plugin.py:219](<./Subspace_LoRA/baseline/feddgc_plugin.py:219>)。
- FFA gate 仍读取不存在的 `client.eval_dataset`，而实际客户端字段是 `local_eval_dataset`。如果不修复，gate 会没有 batch 并退化为默认放行：[ffa_feddgc_ba_plugin.py:415](<./Subspace_LoRA/baseline/ffa_feddgc_ba_plugin.py:415>)。
- 当前名为 `fedsa_feddgc_ba_plugin.py` 的文件实际是 `v3_deltaA`，明确写着对 \(\Delta A\) 做 SVD，而不是论文主方法中的有效更新 \(BA\)：[fedsa_feddgc_ba_plugin.py:34](<./Subspace_LoRA/baseline/fedsa_feddgc_ba_plugin.py:34>)。

所以正式运行前必须冻结一份“方法版本表”：

| Aggregator | 实际 cache operand | 是否递归包含旧 bypass | Gate dataset 字段 | Plugin version |
|---|---|---:|---|---|
| FedIT | effective \(BA+\) bypass | 是 | 明确字段 | SHA/version |
| FLoRA | 待决定 | 待决定 | 明确字段 | SHA/version |
| FFA | \(BA\) | 待确认 | 修复为 `local_eval_dataset` | SHA/version |
| FedSA | 旧 BA 或当前 ΔA 二选一 | 待确认 | `local_eval_dataset` | SHA/version |

### 2. Seed 设计与论文当前文字不一致

> client-selection seed 固定为 42，训练种子为 `{42,43,44}`。

|---:|---:|
| 42 | 42 |
| 43 | 43 |

### 3. Best-round 不适合作为主要统计口径

当前规则是每个方法独立选择 personalized loss 最低的轮次。这里有两个问题：

1. baseline 和 FedReCall 通常会选到不同轮次；
2. 不同轮次参与的是不同的 5 个客户端。

因此，即使两个 run 使用相同 schedule，独立 best-round 后比较的也不是同一组客户端，配对差值不再是严格的同条件配对。同时，取 30 个随机波动点中的最小值会产生 winner’s curse。

建议调整为：

- **主要 rebuttal 统计口径：R25–R29 的每 seed 稳定窗口均值；**
- 主要补充口径：固定 R29；
- best-round：保留为与原 Table 2 对齐的描述性结果，但不要把它作为显著性检验的主口径。

如果必须保留 best-round Table 2，至少应明确：

> Best-round values are reported for consistency with the submitted table; statistical conclusions are based on the pre-registered final-five-round window.

这会比“best-round 结果加一个稳定性检查”更能说服 AC。

## 统计方案评价

统计部分总体正确，但需要补充三点。

### N=3 的 CI 会很宽

自由度 2 的 Student-\(t\) CI 数学上正确，但统计功效很低。不要期待多数结果达到显著性。重点应该是：

- paired effect size；
- mean±SD；
- 3/3 seeds 是否方向一致；
- paired CI；
- 完整三种子原始值。

### 预注册一个主要指标

建议将 `Avg Pers. Loss` 设为 primary endpoint。其他五个指标作为 secondary endpoints。

否则四个聚合器乘六个指标会产生大量比较。如果要对多个指标使用“statistically significant”，应进行 Holm correction；如果不做多重比较校正，就把 CI 明确写成 descriptive uncertainty intervals。

### Gate acceptance rate 需要明确定义分母

建议同时输出：

\[
\text{gate coverage}
=
\frac{\#\text{evaluated caches}}{\#\text{selected clients}},
\]

\[
\text{gate acceptance}
=
\frac{\#\text{passed caches}}{\#\text{evaluated caches}}.
\]

不能将第一次参与、尚无 cache 的客户端当作 gate rejection。

## 验收标准需要修正

“Plugin 从第二轮开始具有 cache 和 gate diagnostics”在随机 10% participation 下不一定成立。

Round 1 的五个客户端可能都没有参加过 Round 0，因此没有任何客户端拥有旧 cache。这是正常现象。

应改为：

- 每个客户端参与结束后必须生成新的 cache 或明确记录无 eligible directions；
- 对任何“此前参加过、当前再次参加”的客户端，必须执行 cache load 和 gate evaluation；
- smoke 固定同一个客户端连续参加 R0、R1，从而保证 R1 一定测试 gate/bypass；
- 正式运行中记录 `cache_origin_round`、`cache_age_rounds`、`gate_evaluated`、`gate_passed`。

这些 cache-age 字段几乎不增加训练成本，却可以直接回答 AC 的 stale-cache 问题。

## 二、最关键的形式化分解

令同一轮参与客户端的最终 LoRA 有效更新为

\[
X_j=sB_jA_j,\qquad
\bar A=\sum_jp_jA_j,\quad
\bar B=\sum_jp_jB_j.
\]

定义两个反事实聚合结果：

\[
X_{\mathrm{eff}}
=
\sum_jp_jX_j
=
s\sum_jp_jB_jA_j,
\]

这是直接平均有效更新，相当于“保持所有本地端点不变，只采用 full-update-style averaging”。

真实 factor-wise 聚合为

\[
X_{\mathrm{fw}}=s\bar B\bar A.
\]

两者差异可以精确写成

\[
\boxed{
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A)
}
\]

这个式子是 rebuttal 最重要的理论结果。它说明：

- \(X_{\mathrm{eff}}\) 中已经包含普通联邦学习的客户端冲突和抵消；
- 右侧是 factor-wise LoRA 额外引入的双线性“因子协方差残差”；
- 如果所有客户端的 \(A\) 相同、所有 \(B\) 相同，或者二者偏差在相关方向上正交，该项消失；
- 当 \(A\) 与 \(B\) 的客户端偏差存在耦合时，分别平均会引入直接平均有效更新中没有的失真。

对客户端方向 \(\phi_i=u_iv_i^\top\)，额外失真为

\[
e_i
=
\langle X_{\mathrm{eff}}-X_{\mathrm{fw}},\phi_i\rangle_F
=
s\sum_jp_j
\big[(B_j-\bar B)^\top u_i\big]^\top
\big[(A_j-\bar A)v_i\big].
\]

并且有界：

\[
|e_i|
\le
s
\sqrt{\sum_jp_j\|(B_j-\bar B)^\top u_i\|_2^2}
\sqrt{\sum_jp_j\|(A_j-\bar A)v_i\|_2^2}.
\]

因此可以给出正式条件：

> 当客户端在方向 \(\phi_i\) 上的 \(A\)-侧和 \(B\)-侧偏差具有非零相关性，且 \(e_i>0\) 时，factor-wise aggregation 相对于有效更新平均产生额外方向衰减。

弱方向为什么更容易出现较大的相对误差，也可以谨慎表达为：

\[
\frac{e_i}{\sigma_i}
\]

会在 \(\sigma_i\) 较小、但因子协方差残差没有同比例减小时变大。也就是说，“弱方向更脆弱”是一个带条件的相对误差结论，不是所有尾部方向必然有用的普遍定理。

一个非常直观的二客户端例子是：

\[
B_2=-B_1,\qquad A_2=-A_1.
\]

此时两个客户端具有完全相同的有效更新：

\[
B_2A_2=B_1A_1,
\]

所以有效更新平均完整保留该方向；但

\[
\bar B=\bar A=0,\qquad \bar B\bar A=0.
\]

即使没有任何 full-update conflict，factor-wise aggregation 也能完全删除更新。这是一个存在性证明，用来说明 LoRA 因子平均确实能够产生独立于一般 FL 冲突的失真；但实证上仍需下面的配对分析。

## 三、最优先补充的实验：同一本地端点的聚合反事实

这是本轮最重要的实验，而且不需要重跑训练，也不改变任何训练代码或主论文逻辑。

对已有 checkpoint 中每一轮完全相同的客户端本地端点，离线计算：

\[
X_{\mathrm{eff}}=s\sum_jp_jB_jA_j,
\qquad
X_{\mathrm{fw}}=s\bar B\bar A.
\]

对于每个客户端、层、奇异方向，同时计算：

\[
\alpha_i^{\mathrm{eff}}
=
\langle X_{\mathrm{eff}},\phi_i\rangle,
\qquad
\alpha_i^{\mathrm{fw}}
=
\langle X_{\mathrm{fw}},\phi_i\rangle.
\]

为了与论文当前 dilution gap 完全一致，定义

\[
C_\sigma(\alpha)=\min(\sigma,\max(\alpha,0)),
\]

\[
D_i^{\mathrm{eff}}
=
\frac{\sigma_i-C_{\sigma_i}(\alpha_i^{\mathrm{eff}})}{\sigma_i},
\]

\[
D_i^{\mathrm{fw}}
=
\frac{\sigma_i-C_{\sigma_i}(\alpha_i^{\mathrm{fw}})}{\sigma_i},
\]

以及

\[
\boxed{
D_i^{\mathrm{factor}}
=
D_i^{\mathrm{fw}}-D_i^{\mathrm{eff}}
}
\]

其中：

- \(D^{\mathrm{eff}}\)：普通有效更新平均已经造成的衰减；
- \(D^{\mathrm{factor}}\)：factor-wise aggregation 额外造成的衰减；
- \(D^{\mathrm{fw}}\)：论文当前测量的总衰减。

实验需要报告：

| Band | 一般聚合 \(D^{eff}\) | factor-wise 额外量 \(D^{factor}\) | 总量 \(D^{fw}\) | \(D^{factor}>0\) 比例 |
|---|---:|---:|---:|---:|
| Head |  |  |  |  |
| Middle |  |  |  |  |
| Tail |  |  |  |  |
| Floor |  |  |  |  |

这是最直接回答 AC 的表格。如果 tail/floor 的 \(D^{factor}\) 明显为正且高于 head/middle，就能严格支持“factor-wise aggregation amplifies directional dilution”。

实验设计上要注意：

- 必须使用完全相同的客户端端点和权重 \(p_j\)，不能比较两个独立训练 run。
- 必须分析所有通过 numerical floor 的方向，不能先按 factor-wise dilution 选出方向再进行比较，否则会产生选择偏差。
- \(D^{factor}\) 必须作为有符号量报告；不能只保留正值，否则结果天然偏向支持假设。
- 统计单位应是 client-round 或 client-layer cluster，不要把成千上万个相关方向假装成独立样本。
- 如果分析“每轮有效增量”，正确公式是
  \[
  s(B_jA_j-B_0A_0),
  \]
  而不是
  \[
  s(B_j-B_0)(A_j-A_0).
  \]
  后者遗漏了 \(B_0\Delta A+\Delta BA_0\) 两个交叉项。

## 四、证明弱方向不是噪声：需要两侧干预，而不只是相关性

你们原来的 motivation 设计已经意识到这一问题。[历史 motivation 总结](</E:/FL/Robust Tail Singular/Subspace_LoRA/plan/MOTIVATION_SECTION_SUMMARY.md:746>)提出过 “global-anchor restoration + source-local removal”，这个逻辑比当前概念 panel (c) 强得多。

建议对当前 BA/rank-32 方向执行以下离线 forward-only 诊断：

1. Restoration：将真实缺失方向补回 factor-wise 全局模型。
2. Removal：从产生该方向的客户端本地模型中删除同一方向。
3. 在与 gate batch 不重叠的 held-out local batch 上评估 loss。
4. 设置严格匹配的对照：

   - owner + 真实方向；
   - owner + 同层、同 band、同范数随机方向；
   - non-owner + 该真实方向；
   - 可选：owner + 能量匹配的 head/middle 方向。

最关键的预期模式是：

\[
\Delta L_{\text{restore, owner}}>0,
\qquad
\Delta L_{\text{remove, owner}}>0,
\]

而且真实方向显著强于随机匹配方向，并且 owner 收益大于 non-owner。

这可以支持：

> 被 FedReCall 选中的弱方向中，存在一个对来源客户端具有可重复、out-of-sample 功能价值的子集。

但仍不要声称：

- 所有 tail/floor 方向都有用；
- tail/floor 天然就是知识；
- 聚合删除弱方向永远有害。

方法中的 numerical floor、dilution selector 和 gate 正是为了从包含噪声的候选池中选择这个有用子集。

理论上也能给出一个简洁条件。若客户端损失关于有效更新是 \(\beta\)-smooth，则对单位方向 \(\phi\)：

\[
L_c(W+\epsilon\phi)
\le
L_c(W)
+
\epsilon\langle\nabla L_c(W),\phi\rangle
+
\frac{\beta}{2}\epsilon^2.
\]

当

\[
\langle\nabla L_c(W),\phi\rangle<-\frac{\beta\epsilon}{2}
\]

时，恢复该方向足以降低客户端损失。Held-out restoration 实验就是对这一有限步长条件的直接经验检验。

## 五、FLoRA 应该如何解释

现有 [FLoRA 实现](</E:/FL/Robust Tail Singular/Subspace_LoRA/baseline/flora.py:1>)明确计算

\[
\sum_jp_jB_jA_j
\]

再截断回 rank \(r\)。所以 Table 2 已经包含一个有效更新聚合基线。

但必须把它解释准确：

- FLoRA 消除了 factor-wise 的交叉因子失真；
- 它仍然存在一般客户端冲突；
- rank-\(r\) SVD 截断还会删除部分弱方向；
- 它与 FedIT 的训练轨迹不同，因而不是严格的同轮因果控制；
- FedReCall 在 FLoRA 上仍有提升并不矛盾，说明 FedReCall 能恢复由“一般平均、rank 截断或 factor-wise 失真”造成的可观测客户端方向损失。

所以建议把 FedReCall 的作用域表述为：

> FedReCall repairs observable client-specific directional attenuation, while factor-wise LoRA aggregation is one important mechanism that can add an extra bilinear distortion.

而不是：

> FedReCall exclusively fixes a failure unique to factor-wise LoRA.

\[

=

当前论文已经证明“真实 factor-wise 协议下存在方向稀释”，但还没有证明“其中有多少是 factor-wise 特有的额外失真”。这正是下一步反事实实验需要回答的问题。

## 1. Reviewer 真正要求证明什么？

Reviewer 质疑的是：

> 论文观察到的方向稀释，究竟只是一般联邦学习中的客户端更新冲突，还是 LoRA 的 factor-wise aggregation 额外造成了稀释？

因此，我们必须构造一个反事实：

- 保持所有客户端、本地训练结果、数据、轮次完全不变；
- 唯一改变聚合方式；
- 比较直接平均有效更新与分别平均 \(A,B\) 的结果。

只有这样才能隔离 LoRA factor-wise aggregation 的独立影响。

## 2. 两种聚合结果是什么？

假设某一轮有多个客户端，每个客户端训练后的 LoRA 有效更新是

\[
X_j=sB_jA_j.
\]

### 反事实：直接平均有效更新

\[
X_{\mathrm{eff}}
=
s\sum_jp_jB_jA_j.
\]

这仍然会产生一般联邦冲突。例如，一个方向只有客户端 1 支持，其他客户端都不支持，那么平均后它自然会减弱。

### 真实 FedIT：分别平均因子

\[
\bar B=\sum_jp_jB_j,\qquad
\bar A=\sum_jp_jA_j,
\]

\[
X_{\mathrm{fw}}=s\bar B\bar A.
\]

它除了包含普通平均效应，还会将不同客户端的 \(B\) 和 \(A\) 交叉配对。

展开后：

\[
X_{\mathrm{fw}}
=
s\sum_j\sum_kp_jp_kB_jA_k.
\]

其中包含：

- \(B_1A_1,B_2A_2\)：客户端真实训练得到的配对；
- \(B_1A_2,B_2A_1\)：从未被任何客户端联合训练过的跨客户端配对。

这些额外的 \(B_jA_k\) 交叉项，就是 factor-wise aggregation 可能产生结构失真的根源。

## 3. 关键恒等式是怎么推导出来的？

我们要比较：

\[
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\left(
\sum_jp_jB_jA_j-\bar B\bar A
\right).
\]

考虑

\[
\sum_jp_j(B_j-\bar B)(A_j-\bar A).
\]

把它展开：

\[
\begin{aligned}
&\sum_jp_j(B_j-\bar B)(A_j-\bar A)\\
=&\sum_jp_jB_jA_j
-\sum_jp_jB_j\bar A
-\sum_jp_j\bar BA_j
+\sum_jp_j\bar B\bar A.
\end{aligned}
\]

由于

\[
\sum_jp_jB_j=\bar B,\qquad
\sum_jp_jA_j=\bar A,\qquad
\sum_jp_j=1,
\]

所以后三项分别变为

\[
-\bar B\bar A-\bar B\bar A+\bar B\bar A.
\]

最终得到

\[
\sum_jp_j(B_j-\bar B)(A_j-\bar A)
=
\sum_jp_jB_jA_j-\bar B\bar A.
\]

因此：

\[
\boxed{
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A)
}
\]

这是一个精确恒等式，不需要任何数据分布、凸性或训练收敛假设。

## 4. 用两个客户端理解最直观

假设两个客户端等权，则：

\[
X_{\mathrm{eff}}
=
s\frac{B_1A_1+B_2A_2}{2},
\]

\[
X_{\mathrm{fw}}
=
s\frac{B_1+B_2}{2}\frac{A_1+A_2}{2}.
\]

两者差异为

\[
\boxed{
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
\frac{s}{4}(B_1-B_2)(A_1-A_2)
}
\]

这意味着：

- 只有 \(B\) 不同、\(A\) 完全相同：没有额外失真；
- 只有 \(A\) 不同、\(B\) 完全相同：没有额外失真；
- \(A\) 和 \(B\) 都存在客户端差异：可能出现额外失真；
- 差异是否表现为“稀释”，取决于这个残差在客户端方向上的投影符号。

例如在一个标量方向上：

\[
b_1=2,\ a_1=2;\qquad b_2=1,\ a_2=1.
\]

两个客户端的有效更新分别为 \(4\) 和 \(1\)，因此直接平均为

\[
X_{\mathrm{eff}}=\frac{4+1}{2}=2.5.
\]

但 factor-wise aggregation 得到

\[
X_{\mathrm{fw}}
=
\frac{2+1}{2}\frac{2+1}{2}
=
2.25.
\]

其中：

- 从客户端 1 的强度 \(4\) 降到 \(2.5\)，是一般联邦平均造成的；
- 从 \(2.5\) 进一步降到 \(2.25\)，是 factor-wise aggregation 额外造成的。

这就是我们希望在真实模型奇异方向上测量的两部分。

## 5. 为什么这是 rebuttal 最重要的理论结果？

因为它同时完成了四件事。

### 第一，它承认 reviewer 正确的部分

一般联邦平均确实会削弱客户端特异方向。我们不再声称所有 dilution 都是 LoRA 独有的。

### 第二，它给出了 LoRA 特异机制

factor-wise aggregation 的额外影响不是模糊的“可能存在”，而是一个明确的矩阵残差：

\[
R_{\mathrm{factor}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A).
\]

这就是一般 full-update averaging 中不存在的部分。

### 第三，它给出了正式发生条件

factor-wise 失真不是无条件发生的。它需要客户端在 \(A\) 和 \(B\) 两侧同时存在耦合差异。

对于方向 \(\phi_i=u_iv_i^\top\)，额外失真是

\[
e_i
=
\langle R_{\mathrm{factor}},\phi_i\rangle_F.
\]

如果

\[
e_i>0,
\]

就表示 factor-wise 结果比有效更新平均在该方向上保留得更少，即产生额外 dilution。

### 第四，它直接决定实验应该测什么

我们不再笼统比较两个不同训练方法，而是对同一轮、同一批本地模型、同一个方向计算：

\[
\alpha_i^{\mathrm{eff}}
=
\langle X_{\mathrm{eff}},\phi_i\rangle,
\]

\[
\alpha_i^{\mathrm{fw}}
=
\langle X_{\mathrm{fw}},\phi_i\rangle.
\]

它们的差：

\[
\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{fw}}
=
\langle R_{\mathrm{factor}},\phi_i\rangle
\]

就是 factor-wise aggregation 在该方向上的独立影响。

## 6. 它是不是完整的证明目标？

不是。完整证据链分为三个层次。

### 理论目标 A：证明额外机制存在

即证明恒等式：

\[
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A).
\]

这一部分已经可以严格完成。

### 实证目标 B：证明真实训练中该残差具有系统性

需要证明：

\[
D_i^{\mathrm{factor}}
=
D_i^{\mathrm{fw}}-D_i^{\mathrm{eff}}
\]

在真实 checkpoint 中：

- 总体显著不为零；
- 多数情况下为正；
- 在 tail/floor 上比 head/middle 更大。

这才能支持：

> factor-wise aggregation amplifies directional dilution.

### 功能目标 C：证明额外稀释的方向不是纯噪声

即通过 held-out restoration/removal 实验，证明其中被 FedReCall 选中的子集：

- 补回后降低 owner loss；
- 删除后增加 owner loss；
- 比匹配随机方向更有用；
- 对 owner 的收益大于 non-owner。

这才能支持：

> A gated subset of the additionally diluted weak directions contains useful client-specific signal.

因此，完整证明链是：

\[
\boxed{
\text{形式化分解}
\rightarrow
\text{真实数据中额外量显著}
\rightarrow
\text{额外丢失的方向具有 owner utility}
}
\]

## 7. 一个重要的结果边界

这个恒等式只能证明 factor-wise aggregation具有产生额外失真的机制，不能单独证明：

- 它在实际训练中一定很大；
- 它一定导致稀释而不是增强；
- tail/floor 一定受到更大影响；
- 被稀释方向一定有功能价值。

后面这些都必须由配对反事实和功能干预实验回答。

另外，因为论文的 dilution gap 使用了 `max` 截断，严格的线性加法首先成立在有符号投影层面：

\[
\sigma_i-\alpha_i^{\mathrm{fw}}
=
(\sigma_i-\alpha_i^{\mathrm{eff}})
+
(\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{fw}}).
\]

# 一、Rebuttal 要回答的三个核心问题

## Q1：一般联邦冲突和 factor-wise 失真能否被严格区分？

理论上通过

\[
X_{\mathrm{eff}}
=
s\sum_jp_jB_jA_j,
\qquad
X_{\mathrm{fw}}
=
s\left(\sum_jp_jB_j\right)
\left(\sum_jp_jA_j\right)
\]

以及

\[
\boxed{
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A)
}
\]

回答。

这一部分证明：factor-wise aggregation 确实具有一般有效更新平均中不存在的额外双线性失真机制。

## Q2：这个额外失真在真实训练中有多大？

通过同客户端、同轮、同本地端点的离线反事实回答：

- 直接有效更新平均 \(X_{\mathrm{eff}}\)；
- 真实 factor-wise 结果 \(X_{\mathrm{fw}}\)；
- 比较二者在同一个客户端奇异方向上的保留率。

这就是你选中的那张核心表格。

## Q3：额外丢失的弱方向是有用信号还是噪声？

- 从 owner 本地模型删除，loss 是否上升？
- 是否优于同能量随机方向？
- 是否对 owner 比 non-owner 更有用？

# 二、第一部分：理论命题

建议在 rebuttal 中明确写成一个 Proposition。

### Proposition：Factorization-specific aggregation residual

对于任意客户端权重 \(p_j\)，满足 \(\sum_jp_j=1\)，有

\[
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A).
\]

对于客户端方向 \(\phi_i=u_iv_i^\top\)，factor-wise 特异失真为

\[
e_i
=
\langle X_{\mathrm{eff}}-X_{\mathrm{fw}},\phi_i\rangle_F.
\]

展开为

\[
e_i
=
s\sum_jp_j
\big[(B_j-\bar B)^\top u_i\big]^\top
\big[(A_j-\bar A)v_i\big].
\]

由此得到：

- \(e_i=0\)：factor-wise 没有在该方向产生额外影响；
- \(e_i>0\)：factor-wise 比有效更新平均保留得更少；
- \(e_i<0\)：factor-wise 在该方向反而保留得更多。

理论部分只能得出“额外机制存在并可被精确识别”，不能预先声称 \(e_i\) 在真实实验中一定为正。

# 三、第二部分：核心同端点反事实实验

## 3.1 实验原则

这是整个因果诊断中最重要的实验。

必须固定：

- 同一轮；
- 同一组参与客户端；
- 完全相同的本地训练后 \(A_j,B_j\)；
- 完全相同的聚合权重 \(p_j\)；
- 完全相同的客户端方向 \(\phi_i\)。

唯一改变的是离线构造的聚合结果：

\[
X_{\mathrm{eff}}
\quad\text{vs.}\quad
X_{\mathrm{fw}}.
\]

因此，不需要重新训练，也不改变主论文实验结果。

## 3.2 每个方向计算的指标

对客户端 \(c\) 的局部有效更新

\[
X_c=sB_cA_c
=
\sum_i\sigma_i\phi_i
\]

计算：

\[
\alpha_i^{\mathrm{eff}}
=
\langle X_{\mathrm{eff}},\phi_i\rangle_F,
\]

\[
\alpha_i^{\mathrm{fw}}
=
\langle X_{\mathrm{fw}},\phi_i\rangle_F.
\]

为保持与论文当前 dilution gap 一致，定义

\[
C_{\sigma_i}(\alpha)
=
\min(\sigma_i,\max(\alpha,0)).
\]

### 一般联邦衰减

\[
D_i^{\mathrm{eff}}
=
\frac{
\sigma_i-C_{\sigma_i}(\alpha_i^{\mathrm{eff}})
}{
\sigma_i
}.
\]

它表示：即使直接平均有效更新，一般客户端冲突已经造成了多少衰减。

### 总 factor-wise 衰减

\[
D_i^{\mathrm{fw}}
=
\frac{
\sigma_i-C_{\sigma_i}(\alpha_i^{\mathrm{fw}})
}{
\sigma_i
}.
\]

这就是当前论文基本测到的总 dilution。

### factor-wise 额外衰减

\[
\boxed{
D_i^{\mathrm{factor}}
=
D_i^{\mathrm{fw}}-D_i^{\mathrm{eff}}
}
\]

必须保留其符号，不能写成 `max(0, ·)`，否则会人为排除 factor-wise 改善方向的情况。

| Band | 一般聚合 \(D^{\mathrm{eff}}\) | Factor-wise 额外量 \(D^{\mathrm{factor}}\) | 总量 \(D^{\mathrm{fw}}\) | \(D^{\mathrm{factor}}>0\) 比例 |
|---|---:|---:|---:|---:|
| Head | median [CI] | median [CI] | median [CI] | % |
| Middle | median [CI] | median [CI] | median [CI] | % |
| Tail | median [CI] | median [CI] | median [CI] | % |
| Floor | median [CI] | median [CI] | median [CI] | % |

\text{Attributable share}
=
\frac{D^{\mathrm{factor}}}{D^{\mathrm{fw}}}

但只在 \(D^{\mathrm{fw}}>\epsilon\) 时计算，并报告有符号分布，不能只报告正值。

## 3.4 预注册假设

建议提前冻结以下假设，避免结果出来后调整口径：

- H1：tail/floor 的 \(D^{\mathrm{factor}}\) 中位数大于 0；
- H2：tail/floor 的 \(D^{\mathrm{factor}}\) 高于 head/middle；
- H3：tail/floor 中 \(D^{\mathrm{factor}}>0\) 的方向比例更高；
- H4：即使 \(D^{\mathrm{eff}}\neq0\)，factor-wise 仍贡献非零的额外量。

H1–H3 支持“factor-wise amplifies directional dilution”。

不需要预设“factor-wise 必须占比超过 50%”。Reviewer 要求的是归因清楚、额外效应真实，而不是强制它成为最大来源。

# 四、第三部分：加入 rank-matched 控制

直接有效更新平均

\[
X_{\mathrm{eff}}=\sum_jp_jX_j
\]

的秩最高可能达到 \(Kr\)，而 factor-wise 结果的秩不超过 \(r\)。Reviewer 可能进一步质疑：

> 观察到的差异究竟来自 factor-wise algebra，还是单纯来自 rank 容量差异？

因此建议再构造：

\[
X_{\mathrm{eff},r}
=
\operatorname{SVD}_r(X_{\mathrm{eff}}),
\]

即 \(X_{\mathrm{eff}}\) 的最佳 rank-\(r\) 近似。

然后比较三个结果：

1. \(X_{\mathrm{eff}}\)：有效更新平均，无 rank 截断；
2. \(X_{\mathrm{eff},r}\)：有效更新平均后截断到 rank \(r\)；
3. \(X_{\mathrm{fw}}\)：真实 factor-wise rank-\(r\) 聚合。

在有符号投影层面可以进一步拆成：

\[
\sigma_i-\alpha_i^{\mathrm{fw}}
=
\underbrace{
\sigma_i-\alpha_i^{\mathrm{eff}}
}_{\text{general FL conflict}}
+
\underbrace{
\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{eff},r}
}_{\text{rank truncation}}
+
\underbrace{
\alpha_i^{\mathrm{eff},r}-\alpha_i^{\mathrm{fw}}
}_{\text{factor-wise vs. rank-matched control}}.
\]

这样能避免 reviewer 认为我们拿 rank-\(r\) 与 rank-\(Kr\) 做不公平比较。

这部分可以作为附录或补充表，不必挤进 rebuttal 主表。

# 五、第四部分：聚合器负对照

当前已有聚合器可以形成很好的机制对照。

| 聚合器 | 一般客户端冲突 | 双因子协方差失真 | 其他方向损失来源 |
|---|---|---|---|
| FedIT | 有 | 有 | 固定 rank |
| FFA-LoRA，公共/冻结 \(A\) | 有 | 理论上应为 0 | 一般平均 |
| FLoRA | 有 | 无直接 cross-factor 失真 | rank-\(r\) SVD 截断 |

FFA-LoRA 中，如果所有客户端使用同一个冻结 \(A\)，那么

\[
\left(\sum_jp_jB_j\right)A
=
\sum_jp_jB_jA.
\]

因此 factor-wise residual 理论上为零。它可以作为分析实现的 sanity check：

\[
D^{\mathrm{factor}}\approx0.
\]

FLoRA 则直接聚合有效更新，再做 rank-\(r\) 截断。它说明：

- 一般方向衰减不只存在于 factor-wise FedIT；
- FedReCall 的适用范围比 factor-wise failure 更广；
- 但 FedIT 中确实可能存在额外的 bilinear amplification。

这里需要诚实调整论文立场：

> Directional attenuation is general; factor-wise aggregation is an additional amplification mechanism, while FedReCall repairs the observable client-specific gap regardless of its exact source.

# 六、第五部分：证明方向不是噪声

核心反事实表只能证明“方向被额外削弱”，不能证明“削弱的是有用知识”。

因此必须增加功能干预。

## 6.1 候选方向

优先选择满足以下条件的方向：

- \(q_i\ge0.6\)；
- 通过原有 numerical floor；
- \(D_i^{\mathrm{factor}}>0\)；
- 候选规则不使用 held-out loss。

可将 factor-wise 特异缺失幅度定义为

\[
\delta_i^{\mathrm{factor}}
=
C_{\sigma_i}(\alpha_i^{\mathrm{eff}})
-
C_{\sigma_i}(\alpha_i^{\mathrm{fw}}).
\]

这样补回的只是“factor-wise 相对于有效更新平均额外删除的部分”，而不是总 dilution。

## 6.2 Restoration

在 factor-wise 全局模型上加入：

\[
C_i
=
\delta_i^{\mathrm{factor}}\phi_i.
\]

比较补回前后的 held-out owner loss：

\[
\Delta L_{\mathrm{restore}}
=
L_{\mathrm{before}}-L_{\mathrm{after}}.
\]

正值表示补回方向有益。

## 6.3 Removal

从 owner 的本地模型中删除相同方向：

\[
X_c^{-}=X_c-C_i.
\]

比较：

\[
\Delta L_{\mathrm{remove}}
=
L(X_c^{-})-L(X_c).
\]

正值表示删除方向会伤害 owner，因此它不是无功能的随机噪声。

## 6.4 必须包含的对照

| 干预 | 作用 |
|---|---|
| Owner + 真实 factor-diluted 方向 | 主要实验 |
| Owner + 同层、同 band、同范数随机方向 | 排除纯能量注入/正则化解释 |
| Non-owner + 同一真实方向 | 证明来源客户端特异性 |
| Owner + 匹配 head/middle 方向 | 验证 tail/floor 候选先验 |
| 可选：奇异向量随机配对 \(u_i v_{\pi(i)}^\top\) | 保留谱能量但破坏学习到的方向结构 |

## 6.5 数据隔离

必须区分：

- candidate selection：只使用矩阵和 dilution 信息；
- gate batch：用于原方法的 one-batch gate；
- held-out evaluation batch：独立评估，不与 gate batch重叠。

需要同时报告：

- gate 前所有候选的 held-out utility；
- gate 接受候选的 held-out utility；
- gate 拒绝候选的 held-out utility。

如果 gate 后的真实方向显著优于随机方向，这将很好地支持：

> tail/floor 是包含信号和噪声的候选池，而 FedReCall 的 gap、numerical floor 和 gate 共同筛出有用子集。

## 为什么 gate-off 是关键，但必须结合 age

在标准 FedReCall 中，客户端 \(c\) 在第 \(t\) 轮使用的 cache age 可以离线精确恢复：

\[
a_c^t=t-t_c^{\mathrm{last}},
\]

其中 \(t_c^{\mathrm{last}}\) 是该客户端上一次参与并刷新 cache 的轮次。

不需要修改训练代码：按照每轮 `client_metrics.csv` 的客户端 ID 顺序维护 `last_selected_round[c]` 即可。

建议 age bins：

\[
1\!-\!2,\quad 3\!-\!5,\quad 6\!-\!10,\quad 11\!-\!20,\quad >20.
\]

首次参与没有 cache，应单独标记 bootstrap，不纳入 gate-age 统计。

### 标准 gate-on run

每个 age bin 报告：

- 样本数；
- gate pass rate；
- gate loss delta：
  \[
  L_{\mathrm{bypass}}-L_{\mathrm{clean}},
  \]
  负值表示 bypass 有益；
- bypass enabled 比例；
- post-local personalized loss。

如果 cache 变旧，预期表现是：

- acceptance rate 随 age 下降；
- gate loss delta 随 age 上升；
- 但被 gate 接受的 cache 仍保持负 loss delta。

这直接回答“acceptance 是增加还是减少，以及是否反映 staleness”。

### Gate-off run

现有 `client_metrics.csv` 已同时提供：

- `clean_pre_local_eval_loss`
- `bypass_pre_local_eval_loss`

因此可以对同一个客户端、同一个当前模型直接计算：

\[
H_c^t
=
L_{\mathrm{bypass}}-L_{\mathrm{clean}}.
\]

这是比比较两个训练 run 更干净的即时伤害指标：

- \(H<0\)：cache 有益；
- \(H>0\)：cache 有害。

在 gate-off run 中按 cache age 统计：

- \(H\) 的均值/中位数；
- \(H>0\) 的比例；
- worst-client loss；
- clean global loss；
- 后续 refreshed cache 的表现。

只有当旧 age bin 的 \(H>0\) 比例或伤害幅度明显上升，才能写：

> Stale caches can become harmful when used unconditionally, while the gate suppresses this failure mode.

否则只能说 gate 拒绝了“不适用 cache”，不能特别归因于年龄。

## Age decay 应如何定义

原表中的“FedReCall + age decay”不够明确。若要运行，最干净的设计不是“gate + decay”，而是：

> gate off + age-only decay

这样可以比较三种安全机制：

1. 无保护：gate off；
2. 只按年龄保护：age decay；
3. 按当前损失保护：quality gate。

建议固定唯一公式，不做 decay 网格：

\[
\eta(a)
=
\eta\,
2^{-(a-1)/10},
\qquad a\ge1.
\]

含义：

- age 1：不衰减；
- age 11：旁路强度减半；
- age 21：变为四分之一。

半衰期 10 轮来自 10% participation 下的期望参与间隔 \(1/0.1=10\)，不是结果驱动调参。

但它需要一个新的、默认关闭的实现分支，并且必须同时影响：

- gate-off forward bypass；
- 被纳入下一轮有效更新/cache construction 的 active cache 强度。

否则训练和缓存更新会使用不同的衰减强度。

这与当前“不修改训练逻辑”的约束冲突。因此我的建议是：

- 先完成前三个无需改代码的 100-round runs；
- 先做 cache-age 分层；
- 只有 AC 明确要求实测 decay，或者 age 分析确认 staleness 是主要问题时，再授权第四个 guarded ablation。

## Moving average 如何回应

不建议增加 moving-average cache run。

原因不是回避，而是当前机制已经执行 periodic refresh：

- 客户端每次参与都会重建 cache；
- 新 cache 覆盖旧 cache；
- 不存在多个历史 cache 文件持续累加；
- moving average 反而会重新引入更久远的方向，并增加 decay coefficient 等额外超参数。

Rebuttal 可以明确写：

> FedReCall does not accumulate historical caches. Each client stores only its latest cache and replaces it after every participation. Staleness arises only from long participation gaps. We therefore analyze performance by cache age and compare the quality gate against unconditional recall; an EMA over historical caches would reintroduce older directions and additional tuning.

## 1. 两种聚合方式有什么区别？

客户端 \(j\) 的 LoRA 更新是

\[
X_j=sB_jA_j.
\]

为了简化，下面暂时省略共同的缩放系数 \(s\)。

### 反事实：直接平均有效更新

如果我们像平均完整模型更新一样，直接平均每个客户端的 \(B_jA_j\)，得到：

\[
X_{\mathrm{eff}}
=
\sum_jp_jB_jA_j.
\]

它已经包含了一般联邦学习中的冲突。

例如一个方向只有客户端 1 支持，其他客户端不支持，那么平均之后它自然会变弱。这不是 LoRA 特有问题。

### 实际的 factor-wise aggregation

FedIT 分别平均两个因子：

\[
\bar B=\sum_jp_jB_j,
\qquad
\bar A=\sum_jp_jA_j,
\]

最后使用：

\[
X_{\mathrm{fw}}=\bar B\bar A.
\]

我们要问的就是：

\[
X_{\mathrm{eff}}-X_{\mathrm{fw}}
\]

到底是什么。

## 2. 为什么分别平均会产生额外项？

把 \(X_{\mathrm{fw}}\) 展开：

\[
\begin{aligned}
X_{\mathrm{fw}}
&=
\left(\sum_jp_jB_j\right)
\left(\sum_kp_kA_k\right)\\
&=
\sum_j\sum_kp_jp_kB_jA_k.
\end{aligned}
\]

这里不仅包含客户端真实训练得到的配对：

\[
B_1A_1,\quad B_2A_2,\quad B_3A_3,
\]

还包含从未由任何单个客户端联合训练过的交叉配对：

\[
B_1A_2,\quad B_1A_3,\quad B_2A_1,\quad \ldots
\]

而直接平均有效更新只包含：

\[
X_{\mathrm{eff}}
=
\sum_jp_jB_jA_j.
\]

所以 factor-wise aggregation 的特殊性就是：

> 它会将一个客户端学到的 \(B_j\) 与另一个客户端学到的 \(A_k\) 重新组合。

这些 cross-client pair 可能保留方向，也可能扭曲、增强或者削弱方向。

## 3. 关键恒等式怎么得到？

定义平均因子：

\[
\bar B=\sum_jp_jB_j,\qquad
\bar A=\sum_jp_jA_j.
\]

考虑每个客户端相对平均值的偏差：

\[
B_j-\bar B,\qquad A_j-\bar A.
\]

将二者相乘并加权平均：

\[
\sum_jp_j(B_j-\bar B)(A_j-\bar A).
\]

展开：

\[
\begin{aligned}
&\sum_jp_j(B_j-\bar B)(A_j-\bar A)\\
=&
\sum_jp_j
\left(
B_jA_j-B_j\bar A-\bar BA_j+\bar B\bar A
\right)\\
=&
\sum_jp_jB_jA_j
-\left(\sum_jp_jB_j\right)\bar A
-\bar B\left(\sum_jp_jA_j\right)
+\left(\sum_jp_j\right)\bar B\bar A.
\end{aligned}
\]

代入

\[
\sum_jp_jB_j=\bar B,\qquad
\sum_jp_jA_j=\bar A,\qquad
\sum_jp_j=1,
\]

得到：

\[
\begin{aligned}
&\sum_jp_j(B_j-\bar B)(A_j-\bar A)\\
=&
\sum_jp_jB_jA_j
-\bar B\bar A
-\bar B\bar A
+\bar B\bar A\\
=&
\sum_jp_jB_jA_j-\bar B\bar A.
\end{aligned}
\]

恢复缩放系数 \(s\)：

\[
\boxed{
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A)
}
\]

右侧就是 factor-wise aggregation 相对于直接有效更新平均的额外残差。

它有点类似于 \(A\) 和 \(B\) 的“客户端协方差”：

- 客户端的 \(A\) 完全相同：残差为 0；
- 客户端的 \(B\) 完全相同：残差为 0；
- \(A\) 和 \(B\) 都发生客户端特异变化：残差可能非零；
- 具体是增强还是削弱，还要看它投影到哪个方向。

## 4. 两客户端情况最容易理解

假设两个客户端等权：

\[
p_1=p_2=\frac12.
\]

直接平均有效更新：

\[
X_{\mathrm{eff}}
=
\frac12(B_1A_1+B_2A_2).
\]

分别平均：

\[
X_{\mathrm{fw}}
=
\frac14(B_1+B_2)(A_1+A_2).
\]

两者差值可以化简成：

\[
\boxed{
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
\frac14(B_1-B_2)(A_1-A_2)
}
\]

这个式子非常直观：

- 如果 \(B_1=B_2\)，差值为 0；
- 如果 \(A_1=A_2\)，差值为 0；
- 只有 \(A\) 和 \(B\) 两侧都发生客户端差异时，分别平均才会额外改变有效更新。

## 5. 一个具体数字例子

暂时把矩阵简化成标量。

客户端 1：

\[
B_1=2,\qquad A_1=2,
\]

所以有效更新是

\[
B_1A_1=4.
\]

客户端 2：

\[
B_2=1,\qquad A_2=1,
\]

所以有效更新是

\[
B_2A_2=1.
\]

### 直接平均有效更新

\[
X_{\mathrm{eff}}
=
\frac{4+1}{2}
=
2.5.
\]

从客户端 1 的方向强度 \(4\) 降到 \(2.5\)，损失了：

\[
4-2.5=1.5.
\]

这部分是一般联邦平均造成的。

### 分别平均因子

\[
\bar B=\frac{2+1}{2}=1.5,
\qquad
\bar A=\frac{2+1}{2}=1.5.
\]

因此：

\[
X_{\mathrm{fw}}=1.5\times1.5=2.25.
\]

相对于直接平均的 \(2.5\)，又额外损失：

\[
2.5-2.25=0.25.
\]

所以总损失为：

\[
4-2.25=1.75,
\]

并且可以精确拆成：

\[
\underbrace{1.75}_{\text{总方向损失}}
=
\underbrace{1.5}_{\text{一般 FL}}
+
\underbrace{0.25}_{\text{factor-wise 额外损失}}.
\]

这就是理论分解最核心的直觉。

## 6. 如何从矩阵差异变成“方向稀释”？

客户端 \(c\) 的有效更新做 SVD：

\[
X_c
=
\sum_i\sigma_i u_iv_i^\top.
\]

定义客户端方向：

\[
\phi_i=u_iv_i^\top.
\]

它在客户端本地的强度是：

\[
\sigma_i.
\]

现在分别测量两种聚合结果在这个方向上的投影：

\[
\alpha_i^{\mathrm{eff}}
=
\langle X_{\mathrm{eff}},\phi_i\rangle_F,
\]

\[
\alpha_i^{\mathrm{fw}}
=
\langle X_{\mathrm{fw}},\phi_i\rangle_F.
\]

于是可以定义三个有符号量。

### 一般联邦平均造成的衰减

\[
g_i^{\mathrm{general}}
=
\sigma_i-\alpha_i^{\mathrm{eff}}.
\]

### Factor-wise 额外造成的变化

\[
g_i^{\mathrm{factor}}
=
\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{fw}}.
\]

### 真实 factor-wise 结果的总衰减

\[
g_i^{\mathrm{total}}
=
\sigma_i-\alpha_i^{\mathrm{fw}}.
\]

它们满足精确恒等式：

\[
\boxed{
g_i^{\mathrm{total}}
=
g_i^{\mathrm{general}}
+
g_i^{\mathrm{factor}}
}
\]

因为：

\[
\begin{aligned}
\sigma_i-\alpha_i^{\mathrm{fw}}
&=
\sigma_i-\alpha_i^{\mathrm{eff}}
+
\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{fw}}.
\end{aligned}
\]

这里没有近似，也没有统计假设。

## 7. Factor-wise 残差为什么可能是正，也可能是负？

定义：

\[
R_{\mathrm{factor}}
=
X_{\mathrm{eff}}-X_{\mathrm{fw}}.
\]

那么：

\[
g_i^{\mathrm{factor}}
=
\langle R_{\mathrm{factor}},\phi_i\rangle_F.
\]

因此：

- \(g_i^{\mathrm{factor}}>0\)：factor-wise 保留得更少，产生额外 dilution；
- \(g_i^{\mathrm{factor}}=0\)：两种聚合在该方向没有区别；
- \(g_i^{\mathrm{factor}}<0\)：factor-wise 反而增强了该方向。

这点非常重要。理论不能预先保证所有方向都满足 \(g_i^{\mathrm{factor}}>0\)。

我们真正要通过实验验证的是：

> 在真实 FedIT checkpoint 中，\(g_i^{\mathrm{factor}}\) 是否整体偏正，并且这种正向额外衰减是否在 tail/floor 上更强。

## 8. 这个理论是否已经证明 tail/floor 更脆弱？

没有。

恒等式只证明：

> Factor-wise aggregation 存在一个可与一般 FL 冲突分离的额外残差。

对于方向 \(i\)，相对额外失真是：

\[
\frac{g_i^{\mathrm{factor}}}{\sigma_i}.
\]

如果 factor-wise 的绝对残差没有随着 \(\sigma_i\) 同比例下降，那么较小的 \(\sigma_i\) 会产生较大的相对误差。

例如：

- head：\(\sigma=10\)，额外误差 \(0.2\)，相对误差 \(2\%\)；
- tail：\(\sigma=0.5\)，额外误差同样是 \(0.2\)，相对误差 \(40\%\)。

但“残差没有同比例下降”是需要真实数据验证的条件，而不是代数恒等式自动保证的。

所以实验表才需要按 band 报告：

| Band | 一般聚合 \(D^{\mathrm{eff}}\) | Factor-wise 额外量 \(D^{\mathrm{factor}}\) | 总量 \(D^{\mathrm{fw}}\) | \(D^{\mathrm{factor}}>0\) 比例 |
|---|---:|---:|---:|---:|
| Head | | | | |
| Middle | | | | |
| Tail | | | | |
| Floor | | | | |

## 9. 为什么论文当前的 dilution gap 不能直接完成这个证明？

论文当前只比较：

\[
\sigma_i
\quad\text{与}\quad
\alpha_i^{\mathrm{fw}}.
\]

因此它测到的是：

\[
\text{一般 FL 冲突}
+
\text{factor-wise 额外失真}.
\]

它没有计算中间反事实：

\[
\alpha_i^{\mathrm{eff}}.
\]

所以 reviewer 才会问：

> 你们看到的稀释是不是普通联邦异质性就已经能够解释？

增加 \(X_{\mathrm{eff}}\) 这个中间反事实以后，我们才能回答：

- 普通平均已经损失多少；
- factor-wise 又额外改变多少；
- 额外部分在不同 band 中如何分布。

## 10. 论文使用了截断 dilution，需要注意什么？

论文定义：

\[
\delta_i
=
\max(0,\sigma_i-\max(\alpha_i,0)).
\]

这个定义会将：

- 负方向投影截断为 0；
- 超过本地强度的投影对应的 gap 截断为 0。

因此，严格的加法恒等式首先成立在有符号投影层面：

\[
\sigma_i-\alpha_i^{\mathrm{fw}}
=
(\sigma_i-\alpha_i^{\mathrm{eff}})
+
(\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{fw}}).
\]

对于论文截断后的指标，应分别计算：

\[
D_i^{\mathrm{eff}}
=
\frac{
\max(0,\sigma_i-\max(\alpha_i^{\mathrm{eff}},0))
}{\sigma_i},
\]

\[
D_i^{\mathrm{fw}}
=
\frac{
\max(0,\sigma_i-\max(\alpha_i^{\mathrm{fw}},0))
}{\sigma_i},
\]

然后定义经验上的增量：

\[
D_i^{\mathrm{factor}}
=
D_i^{\mathrm{fw}}-D_i^{\mathrm{eff}}.
\]

它仍能回答 factor-wise 是否额外加重了 dilution，但不能再声称三个截断量在所有情况下都严格线性相加。

## 11. 最终证明目标是什么？

完整证明由三部分组成。

### 理论部分

证明：

\[
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A).
\]

结论：

> Factor-wise aggregation 确实存在一个区别于一般有效更新平均的额外双线性残差。

### 方向反事实实验

证明真实训练中：

\[
D_i^{\mathrm{factor}}
=
D_i^{\mathrm{fw}}-D_i^{\mathrm{eff}}
\]

在 tail/floor 上系统性为正。

结论：

> Factor-wise aggregation 在普通联邦衰减之上，进一步放大了弱方向的相对稀释。

### 功能干预实验

证明其中被额外稀释的方向：

- 补回后降低 owner loss；
- 删除后提高 owner loss；
- 优于 norm-matched random direction；
- 对 owner 比 non-owner 更有用。

结论：

> Factor-wise 额外丢失的弱方向中，存在对来源客户端具有功能价值的子集，而不只是随机噪声。

因此，这个理论推导最重要的意义不是“单独证明整篇论文正确”，而是：

> 它给出了 reviewer 所要求的因果分界线。没有这个中间反事实，我们只能证明聚合后方向变弱；有了它，我们才能判断其中哪一部分是一般 FL 冲突，哪一部分是 factor-wise LoRA 特有的额外失真。

## 1. \(X_{\mathrm{fw}}\) 里的交叉项是什么？

定义实际的 factor-wise 聚合：

\[
\bar B=\sum_jp_jB_j,\qquad
\bar A=\sum_jp_jA_j,
\]

\[
X_{\mathrm{fw}}=s\bar B\bar A.
\]

把乘积展开：

\[
\begin{aligned}
X_{\mathrm{fw}}
&=s\left(\sum_jp_jB_j\right)
       \left(\sum_kp_kA_k\right)\\
&=s\sum_j\sum_kp_jp_kB_jA_k.
\end{aligned}
\]

这里包括两类项：

- \(j=k\)：同一客户端真实训练得到的 \(B_jA_j\)；
- \(j\neq k\)：客户端 \(j\) 的 \(B_j\) 与客户端 \(k\) 的 \(A_k\) 拼接成的 \(B_jA_k\)。

后者就是交叉客户端的 mismatched cross terms。这些 \(B_jA_k\) 从未在任何客户端上被联合训练过。

例如两个客户端等权重时：

\[
X_{\mathrm{fw}}
=
\frac{s}{4}
\left(
B_1A_1+B_1A_2+B_2A_1+B_2A_2
\right).
\]

其中 \(B_1A_2\) 和 \(B_2A_1\) 是交叉项。

但严谨地说，聚合误差并不只是“多出了交叉项”：同客户端项 \(B_jA_j\) 的系数也由 \(p_j\) 变成了 \(p_j^2\)。所以最好用完整恒等式描述误差，而不是只说“交叉项造成误差”。

## 2. “客户端相对平均值的偏差”是什么？

定义

\[
\Delta B_j=B_j-\bar B,\qquad
\Delta A_j=A_j-\bar A.
\]

它们不是梯度，也不是相对百分比，而是客户端完成本地训练后，其 LoRA 因子与本轮聚合均值之间的矩阵差：

- \(B_j-\bar B\)：客户端 \(j\) 的 \(B\) 偏离全体平均 \(B\) 的部分；
- \(A_j-\bar A\)：客户端 \(j\) 的 \(A\) 偏离全体平均 \(A\) 的部分。

由于它们是中心化偏差，所以

\[
\sum_jp_j(B_j-\bar B)=0,\qquad
\sum_jp_j(A_j-\bar A)=0.
\]

但是这不代表偏差乘积的平均也为零：

\[
\sum_jp_j(B_j-\bar B)(A_j-\bar A)
\neq 0.
\]

这与统计学中的协方差很相似：

\[
\mathbb E[(B-\mathbb E B)(A-\mathbb E A)]
=
\mathbb E[BA]-\mathbb E[B]\mathbb E[A].
\]

因此我们称它为 covariance-like residual。它表示：同一个客户端内部，\(B\) 和 \(A\) 的偏离是否具有协同结构。

需要注意，它是一个矩阵，不一定为正，也不是一个范数：

- 投影到某方向后为正：factor-wise 在该方向产生额外稀释；
- 为负：factor-wise 反而增强该方向；
- 接近零：factor-wise 对该方向没有明显额外作用。

## 3. 关键恒等式怎么得到？

我们要比较两个反事实世界：

\[
X_{\mathrm{eff}}
=
s\sum_jp_jB_jA_j,
\]

即直接平均客户端真实有效更新；以及

\[
X_{\mathrm{fw}}
=
s\bar B\bar A,
\]

即当前实际使用的 factor-wise 聚合。

从中心化偏差的乘积开始：

\[
\sum_jp_j(B_j-\bar B)(A_j-\bar A).
\]

先展开括号：

\[
\sum_jp_j
\left(
B_jA_j-B_j\bar A-\bar BA_j+\bar B\bar A
\right).
\]

分别合并四项：

\[
\begin{aligned}
&\sum_jp_jB_jA_j\\
&\quad-\left(\sum_jp_jB_j\right)\bar A\\
&\quad-\bar B\left(\sum_jp_jA_j\right)\\
&\quad+\left(\sum_jp_j\right)\bar B\bar A.
\end{aligned}
\]

利用定义

\[
\sum_jp_jB_j=\bar B,\qquad
\sum_jp_jA_j=\bar A,\qquad
\sum_jp_j=1,
\]

得到

\[
\begin{aligned}
\sum_jp_j(B_j-\bar B)(A_j-\bar A)
&=
\sum_jp_jB_jA_j
-\bar B\bar A-\bar B\bar A+\bar B\bar A\\
&=
\sum_jp_jB_jA_j-\bar B\bar A.
\end{aligned}
\]

乘上 LoRA scaling \(s\)，便得到：

\[
\boxed{
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A)
}
\]

所以你的理解完全正确：这个关键恒等式就是为了精确推导 \(X_{\mathrm{eff}}-X_{\mathrm{fw}}\)。

## 4. 它为什么对 rebuttal 重要？

它让我们把两种影响严格分开：

\[
\underbrace{\sigma_i-\langle X_{\mathrm{fw}},\phi_i\rangle}
_{\text{实际观察到的总稀释}}
=
\underbrace{\sigma_i-\langle X_{\mathrm{eff}},\phi_i\rangle}
_{\text{普通联邦平均造成的稀释}}
+
\underbrace{\langle X_{\mathrm{eff}}-X_{\mathrm{fw}},\phi_i\rangle}
_{\text{factor-wise 额外影响}}.
\]

其中 \(\phi_i=u_iv_i^\top\) 是客户端 \(i\) 的某个奇异方向。

这正面回答 reviewer：

- 普通联邦学习本来就可能因客户端冲突而稀释方向；
- factor-wise LoRA 在此基础上还可能增加一个可精确定义的双线性残差；
- 这个额外残差到底多大、是否主要集中于 tail/floor、是否删除有用信号，需要实验测量。

- 它在实际训练中一定很大；
- 它一定为正；
- 它一定集中在弱方向；
- 弱方向一定是有用信号。

X_{\mathrm{eff}}-X_{\mathrm{fw}}=0.

对客户端 \(i\) 的局部有效更新

X_i=sB_iA_i

X_{\mathrm{eff}}

\[
X_{\mathrm{fw}}
=s\left(\sum_jp_jB_j\right)
  \left(\sum_jp_jA_j\right),
\]

即 FedIT 实际采用的 factor-wise 聚合。

\alpha_i^{\mathrm{eff}}

\qquad
\alpha_i^{\mathrm{fw}}
=\langle X_{\mathrm{fw}},\phi_i\rangle.

于是有精确分解：

\[
\boxed{
\sigma_i-\alpha_i^{\mathrm{fw}}
=
\underbrace{\sigma_i-\alpha_i^{\mathrm{eff}}}
_{g_i^{\mathrm{general}}}
+
\underbrace{\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{fw}}}
_{g_i^{\mathrm{factor}}}
}
\]

其中：

- \(g_i^{\mathrm{general}}\)：即使服务器直接平均完整有效更新 \(B_jA_j\)，由于客户端异质性与方向冲突仍然产生的衰减；
- \(g_i^{\mathrm{factor}}\)：在固定完全相同的本地客户端更新后，仅仅因为服务器改为分别平均 \(A,B\) 而额外产生的影响；
- 两者之和是实际 FedIT 中观察到的总方向衰减。

举个例子：

\[
\sigma_i=1.0,\qquad
\alpha_i^{\mathrm{eff}}=0.7,\qquad
\alpha_i^{\mathrm{fw}}=0.5.
\]

那么：

\[
g_i^{\mathrm{general}}=0.3,
\qquad
g_i^{\mathrm{factor}}=0.2,
\qquad
g_i^{\mathrm{total}}=0.5.
\]

含义是：这个方向总共损失了 \(0.5\)，其中 \(0.3\) 是一般联邦冲突造成的，额外 \(0.2\) 来自 factor-wise LoRA 聚合。

## 2. 这能回答 reviewer 吗？

理论上，能回答 reviewer 的第一个核心问题：

> 普通联邦平均造成的方向冲突，与 LoRA factor-wise 聚合造成的额外影响，能否被区分？

答案是能，而且是严格区分：

\[
g_i^{\mathrm{general}}
\quad\text{vs.}\quad
g_i^{\mathrm{factor}}.
\]

关键恒等式进一步表明：

\[
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A),
\]

所以 \(g_i^{\mathrm{factor}}\) 不是一个模糊归因，而是一个可精确计算的 LoRA 双线性聚合残差：

\[
g_i^{\mathrm{factor}}
=
\left\langle
s\sum_jp_j(B_j-\bar B)(A_j-\bar A),
\phi_i
\right\rangle.
\]

但仅有理论分解还不够完全说服 reviewer。恒等式只证明：

> factor-wise 聚合相对于有效更新平均，存在一个额外的、可隔离的残差。

它没有自动证明：

- 这个残差在真实训练中足够大；
- 它通常会削弱而非增强客户端方向；
- 它主要集中在 tail/floor；
- 被削弱的弱方向是有用信息而不是噪声。

因此，完整回答必须是：

1. 理论恒等式：证明两种来源可以严格区分；
2. 同端点离线实验：测量两部分各有多大；
3. restoration/removal：验证被额外删除的弱方向具有客户端效用。

## 3. “\(g_i^{\mathrm{factor}}\) 整体偏正”是什么意思？

注意 \(g_i^{\mathrm{factor}}\) 是有符号的：

\[
g_i^{\mathrm{factor}}
=
\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{fw}}.
\]

它有三种可能：

### \(g_i^{\mathrm{factor}}>0\)

\[
\alpha_i^{\mathrm{fw}}<\alpha_i^{\mathrm{eff}}.
\]

说明 factor-wise 聚合比直接平均有效更新保留得更少，即产生了额外方向稀释。

### \(g_i^{\mathrm{factor}}=0\)

两种聚合方式在该方向上没有区别。

### \(g_i^{\mathrm{factor}}<0\)

\[
\alpha_i^{\mathrm{fw}}>\alpha_i^{\mathrm{eff}}.
\]

说明 factor-wise 聚合反而增强了这个方向，至少在这一观测上不能称为 dilution。

因此，“整体偏正”不是要求每个方向都满足 \(g_i^{\mathrm{factor}}>0\)，而是要看整个真实 FedIT checkpoint 中的分布：

- \(g_i^{\mathrm{factor}}\) 的均值或中位数是否大于零；
- cluster-bootstrap 置信区间是否位于零以上；
- \(g_i^{\mathrm{factor}}>0\) 的比例是否明显超过随机平衡水平；
- 这一现象是否跨轮次、客户端和层保持一致。

如果其均值接近零、正负各半，我们只能说 factor-wise 引入了额外扰动，不能说它“系统性稀释”。

## 4. “tail/floor 上更强”是什么意思？

因为 tail/floor 的 \(\sigma_i\) 本来较小，最好看归一化衰减：

\[
d_i^{\mathrm{factor}}
=
\frac{\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{fw}}}
{\sigma_i},
\]

以及

\[
d_i^{\mathrm{general}}
=
\frac{\sigma_i-\alpha_i^{\mathrm{eff}}}
{\sigma_i}.
\]

例如：

- Head：\(\sigma=1.0\)，factor-wise 额外删除 \(0.05\)，相对衰减 \(5\%\)；
- Tail：\(\sigma=0.1\)，factor-wise 额外删除 \(0.05\)，相对衰减 \(50\%\)。

两者绝对误差一样，但 tail 方向损失了自身强度的一半，因此更脆弱。

所以实验最好同时报告绝对值和归一化值，避免“除以较小奇异值后自然变大”的质疑：

| Band | General attenuation | Factor-wise extra | Total attenuation | \(g^{factor}>0\) 比例 |
|---|---:|---:|---:|---:|
| Head |  |  |  |  |
| Middle |  |  |  |  |
| Tail |  |  |  |  |
| Floor |  |  |  |  |

主分析应使用未截断的 signed quantities，保持精确可加性：

\[
d_i^{\mathrm{total}}
=
d_i^{\mathrm{general}}
+
d_i^{\mathrm{factor}}.
\]

论文当前带 `max` 或 clamp 的 dilution gap 可以作为补充指标，但截断后通常不再满足精确加法。

## 5. 什么实验结果才能支持我们的表述？

### 最理想结果

如果发现：

- \(g^{\mathrm{general}}>0\)：承认一般 FL 冲突确实存在；
- \(g^{\mathrm{factor}}>0\)：factor-wise 还增加了可测量的额外衰减；
- tail/floor 的归一化 \(g^{\mathrm{factor}}\) 高于 head/middle；
- tail/floor 中 \(g^{\mathrm{factor}}>0\) 的比例也更高；

那么我们可以非常稳健地回复：

> Directional attenuation is not unique to LoRA: ordinary federated averaging already suppresses client-specific directions under heterogeneity. Our analysis shows that factor-wise LoRA aggregation introduces an additional bilinear residual on top of this general effect, and the same-endpoint diagnostic finds this incremental attenuation to be concentrated in weak tail/floor directions.

中文含义是：

> 方向衰减不是 LoRA 独有的；一般联邦异质性已经会造成衰减。但 LoRA 的 factor-wise 聚合在此基础上引入了额外的双线性残差，而真实 checkpoint 诊断表明，该额外衰减更多集中于弱方向。

### 如果一般 FL 部分更大

假设结果是：

\[
g^{\mathrm{general}}=0.30,\qquad
g^{\mathrm{factor}}=0.05.
\]

这依然支持“factor-wise amplifies dilution”，但不能称它是主要来源。我们应写：

> factor-wise aggregation measurably amplifies a broader FL attenuation phenomenon.

而不能继续写：

> factor-wise aggregation causes directional dilution.

### 如果 \(g^{\mathrm{factor}}\approx0\)

那么 reviewer 基本正确。我们必须把论文重新定位为：

> FedReCall repairs client-specific directional attenuation in federated LoRA; factor-wise mismatch is a possible but not dominant mechanism.

此时不能把 factor-wise 作为核心因果来源。

## 6. 是否必须再跑 full-weight FL？

不一定。对这个“聚合算子因果归因”问题，同端点反事实其实比单独跑一个 full-weight FL 更干净：

\[
\{B_j,A_j\}
\longrightarrow
\begin{cases}
X_{\mathrm{eff}}=\sum_jp_jB_jA_j,\\
X_{\mathrm{fw}}=\bar B\bar A.
\end{cases}
\]

两者使用：

- 相同客户端；
- 相同数据；
- 相同本地训练；
- 相同本地终点；
- 相同聚合权重。

唯一变化就是聚合算子，因此

\[
X_{\mathrm{eff}}-X_{\mathrm{fw}}
\]

具有清晰的因果解释。

真正的 full-weight FL 会同时改变参数化、优化轨迹、通信对象和模型容量，反而不是纯粹的聚合机制对照。不过 rebuttal 中必须诚实地称 \(X_{\mathrm{eff}}\) 为：

> effective-update averaging counterfactual

或者：

> full-update-style aggregation counterfactual

不能把它直接叫作“full-weight fine-tuning baseline”。

## 结论

这套分解能直接回答 reviewer 的“没有区分两种来源”质疑，但只有在真实 checkpoint 上测出 \(g^{\mathrm{factor}}\) 的分布和 band-wise 大小时，才能回答“factor-wise 是否真的系统性放大了稀释”。

最关键的判断标准不是“是否存在 \(X_{\mathrm{eff}}\neq X_{\mathrm{fw}}\)”——这一点代数上已经确定；而是：

\[
\boxed{
g_i^{\mathrm{factor}}
\text{ 是否系统性为正，并是否在 tail/floor 上呈现更强的相对衰减}
}
\]

这决定了最终论文可以说“factor-wise amplifies directional dilution”，还是只能说“directional dilution occurs in federated LoRA”。

# 二、理论部分

## Proposition 1：factorization-specific aggregation residual

对同一轮、同一层的客户端本地终点，定义

\[
X_j=sB_jA_j,
\]

\[
X_{\mathrm{eff}}
=s\sum_jp_jB_jA_j,
\]

\[
X_{\mathrm{fw}}
=s\left(\sum_jp_jB_j\right)
  \left(\sum_jp_jA_j\right)
=s\bar B\bar A.
\]

则：

\[
\boxed{
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
s\sum_jp_j(B_j-\bar B)(A_j-\bar A)
}
\]

还可以写成客户端两两差异形式：

\[
\boxed{
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
\frac{s}{2}
\sum_{j,k}p_jp_k
(B_j-B_k)(A_j-A_k)
}
\]

这个形式给出很直观的发生条件：

- 所有客户端 \(A_j\) 相同，则残差为零；
- 所有客户端 \(B_j\) 相同，则残差为零；
- 客户端 \(A,B\) 的联合偏差互相抵消，则残差也可能为零；
- 异质性导致 \(A,B\) 产生相关的客户端偏差时，残差通常非零。

两个等权客户端时：

\[
X_{\mathrm{eff}}-X_{\mathrm{fw}}
=
\frac{s}{4}(B_1-B_2)(A_1-A_2).
\]

这回答了 reviewer 的第一个质疑：一般联邦冲突和 LoRA 因子聚合失真在数学上可以严格区分。

## Proposition 2：方向级精确分解

对客户端 \(i\) 的本地奇异方向

\[
\phi_i=u_iv_i^\top,
\qquad
\langle X_i,\phi_i\rangle_F=\sigma_i,
\]

定义：

\[
\alpha_i^{\mathrm{eff}}
=\langle X_{\mathrm{eff}},\phi_i\rangle_F,
\qquad
\alpha_i^{\mathrm{fw}}
=\langle X_{\mathrm{fw}},\phi_i\rangle_F.
\]

使用未截断、有符号的量：

\[
g_i^{\mathrm{general}}
=
\sigma_i-\alpha_i^{\mathrm{eff}},
\]

\[
g_i^{\mathrm{factor}}
=
\alpha_i^{\mathrm{eff}}-\alpha_i^{\mathrm{fw}},
\]

\[
g_i^{\mathrm{total}}
=
\sigma_i-\alpha_i^{\mathrm{fw}}.
\]

于是：

\[
\boxed{
g_i^{\mathrm{total}}
=
g_i^{\mathrm{general}}
+
g_i^{\mathrm{factor}}
}
\]

以及

\[
g_i^{\mathrm{factor}}
=
s\sum_jp_j
\left[(B_j-\bar B)^\top u_i\right]^\top
\left[(A_j-\bar A)v_i\right].
\]

因此，factor-wise 产生额外方向稀释的精确条件是：

\[
\boxed{
g_i^{\mathrm{factor}}>0
}
\]

即

\[
\alpha_i^{\mathrm{fw}}
<
\alpha_i^{\mathrm{eff}}.
\]

建议再报告归一化量：

\[
d_i^{(\cdot)}=\frac{g_i^{(\cdot)}}{\sigma_i}.
\]

这样可以区分：

- absolute extra attenuation：额外删除了多少强度；
- relative extra attenuation：额外删除了该方向自身强度的多大比例。

论文当前带 `max`/clamp 的 dilution gap 保留为兼容性副指标。主因果分解必须使用未截断的 signed quantities，否则无法直接解释为投影残差。

## Proposition 3：弱方向“有用而非噪声”的充分条件

设在 factor-wise 全局模型上补回

\[
C_i=\delta_i^{\mathrm{factor}}\phi_i.
\]

如果 owner 的损失 \(L_i(W)\) 关于有效权重是 \(\beta\)-smooth，则：

\[
L_i(W+C_i)
\le
L_i(W)
+
\langle\nabla L_i(W),C_i\rangle
+
\frac{\beta}{2}\|C_i\|_F^2.
\]

因此，只要：

\[
\boxed{
\langle\nabla L_i(W),C_i\rangle
<
-\frac{\beta}{2}\|C_i\|_F^2
}
\]

补回该方向就会降低 owner loss。

这给出了“弱方向何时是有用信号”的形式化充分条件。FedReCall 的 one-batch gate 是这个条件的经验损失探针；独立 held-out evaluation 则负责验证 gate 没有过拟合该 batch。

理论上不要声称所有 tail/floor 都有用。正确命题是：

> Tail/floor forms a candidate pool containing both signal and noise; the gap, numerical floor, and gate select an owner-useful subset.

# 三、实验一：同端点因果分解

这是本方向最关键的实验。

## 3.1 唯一允许变化的变量

固定：

- 同一训练轮次；
- 同一组参与客户端；
- 完全相同的本地训练后 \(A_j,B_j\)；
- 相同客户端权重 \(p_j\)；
- 相同 owner 方向 \(\phi_i\)。

只离线构造：

\[
X_{\mathrm{eff}}
\quad\text{和}\quad
X_{\mathrm{fw}}.
\]

这样不会修改训练逻辑，也不会改变 Table 2。相较于单独跑 full-weight FL，这个 same-endpoint counterfactual 的因果控制更干净，因为唯一差异就是聚合算子。

必须称它为：

> effective-update averaging counterfactual

不能直接称为 full-weight fine-tuning baseline。

## 3.2 数据需求

每个分析轮次需要：

- 所有参与客户端本地训练后的 \(A_j,B_j\)；
- 聚合权重 \(p_j\)；
- LoRA scaling \(s\)；
- 层名、轮次、客户端 ID；
- server factor-wise 聚合结果，或能由客户端端点重新计算；
- 配置、代码 SHA、源 checkpoint 路径。

优先分析所有具有完整端点的轮次。若不完整，预先冻结：

\[
R0,\ R10,\ R20,\ R29
\]

或等价的 early/middle/late/final 轮次，不能看完结果再挑轮。

如果现有数据确实没有完整端点，则运行独立的 diagnostic FedIT trajectory：训练算法和超参数不变，只保留分析所需的客户端端点；不得替换主表结果。

## 3.3 方向划分

严格沿用论文定义：

- Head：\(q<0.2\)
- Middle：\(0.2\le q<0.6\)
- Tail：\(0.6\le q<0.9\)
- Floor：\(q\ge0.9\)

所有超过 numerical floor 的方向都进入因果分解。不能先用 \(g^{\mathrm{factor}}>0\) 筛选，否则会人为制造“整体偏正”。

## 3.4 每个方向的计算流程

对每个 owner-client、round、layer：

1. 计算 \(X_i=sB_iA_i\)。
2. 对 \(X_i\) 做 SVD，得到 \(\sigma_i,\phi_i\)。
3. 构造 \(X_{\mathrm{eff}}\)。
4. 构造 \(X_{\mathrm{fw}}\)。
5. 计算 \(\alpha_i^{\mathrm{eff}},\alpha_i^{\mathrm{fw}}\)。
6. 计算 \(g^{\mathrm{general}},g^{\mathrm{factor}},g^{\mathrm{total}}\)。
7. 计算对应的归一化量 \(d=g/\sigma\)。
8. 保留正值、零值和负值，不裁剪。

同时做恒等式审计：

\[
\frac{
\left\|
X_{\mathrm{eff}}-X_{\mathrm{fw}}
-
s\sum_jp_j(B_j-\bar B)(A_j-\bar A)
\right\|_F
}{
\|X_{\mathrm{eff}}-X_{\mathrm{fw}}\|_F+\epsilon
}
<10^{-6}.
\]

## 3.6 预注册假设

- H1：一般 FL 衰减 \(d^{general}\) 非零；
- H2：tail/floor 的 \(d^{factor}\) 中位数大于零；
- H3：tail/floor 的 \(d^{factor}\) 高于 head/middle；
- H4：tail/floor 中 \(d^{factor}>0\) 的比例更高；
- H5：上述结论同时出现在绝对量和相对量中，或至少相对量稳定成立。

H1 承认 reviewer 指出的通用 FL 现象；H2–H4 才支持 “factor-wise amplifies directional dilution”。

不需要证明 factor-wise 占总衰减超过 50%。只需要证明其额外作用真实、可测且具有结构性。

# 四、实验二：rank-matched 与负对照

## 4.1 Rank-matched control

因为

\[
\operatorname{rank}(X_{\mathrm{eff}})\le Kr,
\qquad
\operatorname{rank}(X_{\mathrm{fw}})\le r,
\]

reviewer 可能认为差异只是 rank 容量差异。

构造：

\[
X_{\mathrm{eff},r}
=
\operatorname{SVD}_r(X_{\mathrm{eff}}),
\]

即 \(X_{\mathrm{eff}}\) 的最佳 rank-\(r\) 近似。

进一步分解：

\[
\begin{aligned}
\sigma_i-\alpha_i^{\mathrm{fw}}
={}&
\underbrace{\sigma_i-\alpha_i^{\mathrm{eff}}}
_{\text{general FL}}
+
\underbrace{\alpha_i^{\mathrm{eff}}
-\alpha_i^{\mathrm{eff},r}}
_{\text{rank budget}}\\
&+
\underbrace{\alpha_i^{\mathrm{eff},r}
-\alpha_i^{\mathrm{fw}}}
_{\text{factor-wise vs. best rank-}r}.
\end{aligned}
\]

如果 \(X_{\mathrm{fw}}\) 在 tail/floor 上仍明显差于 \(X_{\mathrm{eff},r}\)，就说明结果不能只由 rank 容量解释。

这一项是 P1 强控制，不取代原始的精确残差分解。

## 4.2 FFA-LoRA 负对照

FFA-LoRA 中所有客户端共享冻结的 \(A_0\)：

\[
A_j-\bar A=0.
\]

因此理论上：

\[
X_{\mathrm{eff}}-X_{\mathrm{fw}}=0.
\]

把同一分析管线用于 FFA-LoRA，应得到：

\[
d^{\mathrm{factor}}\approx0.
\]

它有两个作用：

- 验证分析实现没有人为制造 factor-wise residual；
- 证明我们的量确实捕捉了双因子分别聚合，而不是所有联邦异质性。

## 4.3 FLoRA 作为补充参考

FLoRA 聚合有效更新后进行 rank-\(r\) SVD，因此可以说明：

- 一般方向衰减在没有交叉因子失真的情况下也存在；
- rank 截断也是另一种方向损失来源；
- FedReCall 修复的是可观测的客户端方向缺口，其适用范围可以宽于 FedIT 的 bilinear mismatch。

但 FLoRA 的训练轨迹不同，因此它只能作为外部机制参考，不能代替同端点因果实验。

# 五、实验三：弱方向的功能因果干预

因果分解只能证明方向被额外削弱，不能证明它有用。因此必须做 restoration/removal。

## 5.1 候选选择

仅选择：

- \(q\ge0.6\)；
- \(\sigma_i\) 通过原有 numerical floor；
- \(g_i^{\mathrm{factor}}>0\)；
- 不使用 gate batch 或 held-out loss 选择方向。

定义有界的 factor-specific missing amplitude：

\[
\delta_i^{\mathrm{factor}}
=
C_{\sigma_i}(\alpha_i^{\mathrm{eff}})
-
C_{\sigma_i}(\alpha_i^{\mathrm{fw}}),
\]

其中

\[
C_{\sigma}(\alpha)=\min(\sigma,\max(\alpha,0)).
\]

然后组装 owner cache：

\[
C_c=\sum_{i\in\mathcal S_c}
\delta_i^{\mathrm{factor}}\phi_i.
\]

这里补回的只是 factor-wise 相对于有效更新平均额外删除的部分，而不是总 dilution。

## 5.2 Restoration

在 factor-wise 全局模型上分别评估：

\[
W_{\mathrm{fw}}
\quad\text{和}\quad
W_{\mathrm{fw}}+C_c.
\]

定义：

\[
\Delta L_{\mathrm{restore}}
=
L_c(W_{\mathrm{fw}})
-
L_c(W_{\mathrm{fw}}+C_c).
\]

正值表示补回有益。

建议同时做：

- cache-level restoration：最贴近 FedReCall 实际使用方式；
- sampled direction-level restoration：获得方向效用分布。

## 5.3 Removal

从 owner 本地有效更新中删除相同分量：

\[
X_c^{-}=X_c-C_c.
\]

定义：

\[
\Delta L_{\mathrm{remove}}
=
L_c(X_c^{-})-L_c(X_c).
\]

正值表示删除伤害 owner，从而支持该方向不是无功能噪声。

## 5.4 必须包含的控制

| 干预 | 排除的解释 |
|---|---|
| Owner + 真实 factor-diluted cache | 主要结果 |
| Owner + 同层、同 band、同范数随机方向 | 排除仅仅增加能量/低秩正则化 |
| Owner + shuffled \(u_iv_{\pi(i)}^\top\) | 保留谱强度但破坏学习到的方向结构 |
| Non-owner + 同一真实 cache | 检验客户端特异性 |
| Owner + norm-matched head/middle cache | 检验 tail/floor 选择先验 |
| Owner removal + random removal | 验证真实方向删除更有害 |

随机方向必须匹配：

- 层；
- band 或候选数量；
- rank；
- Frobenius norm；
- 注入总幅度。

否则 reviewer 可以把差异归因于注入能量。

## 5.5 数据隔离

严格分开：

1. Candidate selection：只使用矩阵、奇异值和 dilution 信息；
2. Gate batch：只用于 one-batch quality gate；
3. Held-out batch：只用于最终效用评价，与 gate batch 不重叠。

分别报告：

- 所有候选；
- gate accepted；
- gate rejected。

理想现象是：

- accepted 真实方向在 held-out 上显著有益；
- rejected 方向无益或有害；
- 真实方向优于随机方向；
- owner improvement 高于 non-owner。

这会支持：

> Weak directions are not assumed to be universally useful; FedReCall identifies an owner-useful subset using a loss-blind structural candidate rule followed by a local quality gate.

## 5.6 功能结果表

| Intervention | Owner held-out \(\Delta L\) | 改善比例 | Non-owner \(\Delta L\) | Owner advantage |
|---|---:|---:|---:|---:|
| Real factor-specific restore |  |  |  |  |
| Norm-matched random restore |  |  |  |  |
| Shuffled-pair restore |  |  |  |  |
| Head/middle restore |  |  |  |  |
| Real removal |  |  | — | — |
| Random removal |  |  | — | — |

Loss 是主指标；ROUGE-L 可以作为补充，避免短 held-out 文本导致方差过大。

# 六、统计设计

不能把数十万个方向视为独立重复。

建议采用：

- 原始观测：direction；
- 一级 cluster：client-round；
- 可选层级：client-round-layer；
- 功能实验独立单位：client-round 或 client；
- 若有多 seed，seed 放在最外层。

报告：

- median、IQR；
- cluster-bootstrap 95% CI；
- \(d^{factor}>0\) 比例；
- tail/floor 与 head/middle 的同 client-round-layer 配对差；
- restoration 相对 random 的配对差；
- owner 相对 non-owner 的配对差。

不使用方向数量制造极小 \(p\)-value。这里效应大小、置信区间和跨 cluster 一致性比显著性标签更重要。
