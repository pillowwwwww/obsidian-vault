## 项目背景

项目路径：

`Subspace_LoRA/`

论文方向：Federated Learning + LoRA 微调。项目代号 FedDGC。核心问题是：在任务异构的 FL + LoRA 场景中，FedAvg 聚合会选择性稀释客户端 ΔW = scaling * B A 中的 tail/floor singular directions。这些方向在 motivation 实验证明具有客户端个性化知识和功能价值。

主要文档：

- `Subspace_LoRA/plan/motivation_最终版.md`
- `Subspace_LoRA/plan/FedDGC_B_METHOD.md`
- `Subspace_LoRA/plan/v9 main experiments plan.md`
- `Subspace_LoRA/plan/baseline_integration_plan_a94a1642.plan.md`

当前 FedDGC 正式方法版本是 v9：

- 方法对象：完整 LoRA 更新矩阵 `ΔW = scaling * B @ A`
- 方法收缩为：tail-restricted frozen bypass personalization
- cache 存储 tail/floor singular directions：`C_c = Σ δ_i u_i v_i^T`
- 不再把 correction 融入 LoRA 参数，也不上传 correction
- bypass 只作为 forward hook 加到客户端本地训练和 personalized eval 中
- 服务器聚合仍只聚合干净的 LoRA A/B 参数
- 强度采用 eta calibration：
  `lambda_{c,l} = eta * ||s_l B_l A_l||_F / (||C_{c,l}||_F + eps)`
- 当前主实验正在进一步测试 `eta = 1.5, 2.0, 3.0, 4.0`
