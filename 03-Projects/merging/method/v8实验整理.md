v8 Gate逻辑：
if eval_loss(AB) > eval_loss(AB + λC):
    启用 bypass
else:
    不启用 bypass
等价写法：
init_delta = eval_loss(AB) - eval_loss(AB + λC)

if init_delta > 0:
    enable bypass
else:
    disable bypass
如果 init_delta 很大，说明当前这个 λC 对客户端本地数据明显有帮助。但“差值越大就一定用更大 λ”只能作为直觉，最好不要直接线性放大。更稳的是在 gate batch 上试几个离散 λ：
