#### Step 0: Configuration (`main.py`)

- Add a new argument `cfg.subspace.rank_budget` (integer).
    
- This represents the global server rank budget ($R$) for the reference subspace.
    

#### Step 1: Client-Side Gauge Fixing (`client.py`)

- **Logic:** Before uploading weights to the server, process the LoRA matrices ($B \in \mathbb{R}^{d \times r_i}$ and $A \in \mathbb{R}^{r_i \times k}$):
    
    1. Perform Reduced QR Decomposition on $B$:
        
        $$B_i = U_i R_i$$
        
        (Where $U_i$ is orthonormal $d \times r_i$, $R_i$ is upper-triangular).
        
    2. Absorb the residual $R_i$ into the adapter $A$:
        
        $$A'_i = R_i A_i$$
        
    3. **Output:** The client must upload $U_i$ and $A'_i$ instead of the original $B, A$.
        

#### Step 2: Server-Side Consensus Projector (`model_aggregator.py`)

- **Logic:** Inside the aggregation function:
    
    1. Construct the Weighted Consensus Projector matrix $C$ (shape $d \times d$):
        
        $$C = \sum_{i \in \text{Clients}} \rho_i (U_i U_i^T)$$
        
        (Where $\rho_i$ is the weight of client $i$, typically based on sample size).
        
    2. Compute the **Global Reference Subspace** $U_{ref}$:
        
        - Perform Eigendecomposition on $C$.
            
        - Select the top $R$ eigenvectors (where $R$ is `cfg.subspace.rank_budget`).
            
        - $U_{ref}$ has shape $d \times R$.
            

#### Step 3: Coordinate Translation & Aggregation (`model_aggregator.py`)

- **Logic:**
    
    1. Project each client's modified adapter $A'_i$ into the reference subspace:
        
        $$\tilde{A}_i = (U_{ref}^T U_i) A'_i$$
        
    2. Aggregate the projected coordinates:
        
        $$A_{global} = \sum_{i \in \text{Clients}} \rho_i \tilde{A}_i$$
        
    3. The global model state is now represented by the pair $(U_{ref}, A_{global})$.
        

#### Step 4: Redistribution / Truncation (`model_aggregator.py`)

- **Logic:** Prepare the weights to be sent back to clients. Since clients have heterogeneous ranks ($r_i$):
    
    - For a client with rank $r_i$ (where $r_i \le R$), generate specific weights by truncating the global parameters:
        
        - $B_{new} = U_{ref}[:, 0:r_i]$ (First $r_i$ columns)
            
        - $A_{new} = A_{global}[0:r_i, :]$ (First $r_i$ rows)
            
    - Ensure the aggregator returns these truncated weights in a format the client can load as standard LoRA.
